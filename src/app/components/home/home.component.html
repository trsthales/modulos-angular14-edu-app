🚀 Conceitos Fundamentais

Declarations

Componentes, diretivas e pipes que pertencem ao módulo. Cada um pode ser declarado em apenas UM módulo.

declarations: [AppComponent, HeaderComponent]

Imports

Outros módulos cujas funcionalidades são necessárias neste módulo.

imports: [BrowserModule, RouterModule, FormsModule]

Exports

Componentes, diretivas e pipes que podem ser usados por outros módulos que importarem este módulo.

exports: [CommonModule, CardComponent, FormatPipe]

Providers

Serviços que estarão disponíveis para injeção de dependências. No Angular 14+, prefira usar providedIn: 'root'.

providers: [AuthService, DataService]

Bootstrap

Componente raiz que será inicializado. Apenas no módulo raiz (AppModule).

bootstrap: [AppComponent]

⚠️ Regras Importantes

  • BrowserModule deve ser importado APENAS no AppModule. Em feature modules, use CommonModule.
  • Um componente/diretiva/pipe pode ser declarado em apenas UM módulo.
  • Use forRoot() no AppModule e forChild() em feature modules para configurar rotas.
  • O Core Module deve ser importado apenas uma vez no AppModule.
  • O Shared Module deve usar exports para disponibilizar seus recursos.

💡 Lazy Loading

Os módulos de Produtos e Usuários usam Lazy Loading, o que significa que eles são carregados apenas quando você navega para suas rotas. Isso melhora significativamente o tempo de carregamento inicial da aplicação.

Abra o DevTools (F12) e vá para a aba Network para ver os chunks sendo carregados quando você navega para essas rotas pela primeira vez!
