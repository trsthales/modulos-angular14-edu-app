🔍 Roteamento em Feature Modules

Esta página demonstra como o roteamento funciona dentro de um Feature Module. A rota completa é /produtos/{{ produtoId }}.

  • Base path: /produtos (definido em app.routes.ts)
  • Child path: :id (definido em produtos.module.ts)
  • URL final: /produtos/{{ produtoId }}

📚 Como funciona:

  1. No app.routes.ts, definimos a rota lazy: /produtos
  2. No produtos.module.ts, usamos RouterModule.forChild()
  3. As rotas filhas são relativas ao path base
  4. O Angular combina os paths automaticamente
