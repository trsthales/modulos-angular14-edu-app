Este componente faz parte do ProdutosModule, um Feature Module que é carregado sob demanda (lazy loading).

📚 Características deste Feature Module:

  • ✓ Usa RouterModule.forChild() (não forRoot)
  • ✓ Carregado apenas quando navegamos para /produtos
  • ✓ Possui suas próprias rotas e componentes
  • ✓ Importa o SharedModule para reutilizar componentes
